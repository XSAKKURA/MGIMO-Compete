# Устройство агента

Вход — запрос руководителя и разрешённые материалы. Контекст собирается последовательно: карточка решения, факты с адресами, варианты, финансовая модель, условия решения. Исследование останавливается, когда следующий источник уже не изменит выбор. Руководитель получает рекомендации для продукта и коммуникаций и сохраняемую ревизию состояния.

Постоянные инструкции лежат в src, повторяемая методика в skills, данные и результаты конкретного примера в demo. MASTER.md — собранная копия всей методики для одного вложения. Знания о заказчике не встроены в постоянные инструкции. Блок состояния хранит происхождение данных и пороги, поэтому продолжение возможно без истории переписки.

| Процедура | Инструмент | Проверяемый результат |
|---|---|---|
| Постановка и реестр | LLM, доступные читатели документов/таблиц и браузер среды | Локаторы, неизвестные, допущения |
| Выбор | LLM по skills/02-choice.md | Реальные альтернативы, действие пользователя, подтверждение обещания |
| Экономика | LLM; для учебного кейса Python 3 Decimal | Когорты, месяцы до декабря, прибыль и граница |
| Возобновление | JSON и протокол skills/04-handoff.md | Изменённые основания и решение; повтор события пропускается |
| Сборка | Python 3 стандартной библиотеки | Один неизменяемый при переносе MASTER.md |

Основные промпты приведены полностью в MASTER.md, стартовая реплика в README. В демонстрации использованы ChatGPT/Codex для разработки и слепого прогона, браузер для чтения условий и PDF партнёра, pdftotext для сверки таблиц, Git и Python для воспроизводимой сборки и проверки. В работе у пользователя достаточно одной языковой модели и материалов. Реальные интервью, интеграции с биллингом и персональные данные не использовались. Экономия по сравнению с аналитиком не измерялась. Денежный счёт и токены среды недоступны. Оценка расходов отдельного запуска = входные и выходные токены × их тарифы + платные обращения к инструментам + ручные часы × ставку. Роль человека — задать вопрос и утвердить инвестиционное решение; агент не выдаёт финансирование.

Независимый прогон выявил неоднозначность пар значений когорт. В inputs.json добавлен словарь с единицами, порядком элементов и сроком действия допущения. Числа учебного прогноза и журнал испытаний доступны в demo и verification. При отсутствии инструментов посещение сайтов, запись файлов и точный биллинг модели зависят от среды. Пользователь может перенести состояние и выдержки вручную.
