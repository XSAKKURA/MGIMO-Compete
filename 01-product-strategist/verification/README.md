# Приёмка

Открывайте пустой чат с MASTER.md. Файл с ожидаемыми ответами оставьте у проверяющего. Текст может отличаться, числа, основания и решение проверяются отдельно.

| Вход | Критерий до запуска |
|---|---|
| Бриф + inputs.json | База 279 млн ₽, годовой прирост +430 тыс. / −58 тыс. ₽, обе ветви ниже цели. Выбор масштаба зависит от контроля, условий доступа и сметы |
| Только demo/state.json | Восстановить исходную рекомендацию и повторить расчёт; не выдавать деньги за одобренные |
| N1 | Сохранить событие, оставить числа и решение |
| F1 | 610 000 − 700 000 = −90 000 ₽; прибыль 278,91 млн ₽. При этой смете расширение отклонить. Новый порог достижения цели 13 400 месяцев. Квартальную окупаемость оставить открытой |
| C1 | Записать конфликт, приостановить реальные показы до сверки и проверки отзыва. Экономика не меняется |
| R1 после F1 | Не вычитать повторно 700 000 ₽ и не увеличивать ревизию за уже применённое событие |
