# Стратег Фабрики продуктов

Агент для руководителя цифрового продукта. Из запроса и материалов он формирует продуктовую и коммуникационную стратегии, сравнивает вложения с обычным обслуживанием и сохраняет основания решения для следующей встречи.

**Запуск в проектной папке.** Откройте эту папку в среде с LLM и чтением Markdown. Отправьте:

> Прочитай MASTER.md и работай по нему. Возьми demo/brief.md и demo/inputs.json. К концу I квартала нужно решить, стоит ли выделять разработчиков. Начни с вопроса, который сильнее всего изменит это решение. Доведи работу до пяти частей стратегии. Сохрани состояние.

**Запуск в обычном чате.** Передайте [MASTER.md](MASTER.md) как инструкцию, приложите [бриф](demo/brief.md) и [таблицу входов](demo/inputs.json), затем отправьте тот же запрос. Если вложения недоступны, вставьте их текстом. Для своей задачи замените оба входа своими материалами и укажите решение, срок и владельца. Без каталога файлы и состояние передаются вручную. Поиск по сайтам требует браузера или предоставленной выдержки.

**Продолжение.** Скажите «Сохрани». В новом чате передайте MASTER.md, блок состояния и только изменившиеся данные. Готовый пример состояния находится в [demo/state.json](demo/state.json). Команда «Продолжи. Что изменилось и требуется ли другое решение?» запускает пересмотр. «Статус» показывает следующий шаг. «Стоп» завершает работу с сохранением.

| Что открыть | Для чего |
|---|---|
| [MASTER.md](MASTER.md) | Единый переносимый файл, включая все навыки |
| [skills](skills) | Редактируемые процедуры исследования, выбора, экономики и сохранения |
| [Демонстрация](demo/strategy.md) | Итог по учебному оператору с пятью разделами и квартальными решениями |
| [Проверка](verification/README.md) | Холодный старт, перенос, конфликт, повтор и смена решения |
| [Описание](DESCRIPTION.md) | Устройство агента, инструменты, затраты, ограничения |

Нужен доступ к выбранной пользователем языковой модели. API-ключи, собственный сервер и платные интеграции проекту не требуются. Если есть Python 3, запустите из этой папки `python3 tools/economics.py` для независимого пересчёта двух сценариев. В чате расчёт выполняется по тем же формулам. После изменения навыков пересоберите единый файл командой `python3 tools/bundle.py`.
